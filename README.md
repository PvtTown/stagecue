# StageCue

演绎活动的**个性化推荐**与**开票提醒**（面向 iPhone：日历 + 邮件草稿）。

## 功能

- **只推未开票**：已开票场次默认不进推荐（秒空难追）
- **先问兴趣**：每场带外行可读简介，再选「感兴趣 / 跳过」
- **感兴趣后排提醒**：开票**前一天** + 开票**前 5 分钟**
- **提醒四要素**：开票时间、场馆、票价、购票链接（缺一不可）
- **手机通道**：导出 `.ics` 导入 iPhone 日历（主）；邮箱草稿摘要（辅）；浏览器通知（页开着时）
- **本地持久化**：`localStorage`（口味 / 兴趣 / 邮箱 / 提醒）

> 不做自动抢票或代下单。

## 开发

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## 数据

当前使用 `src/data/events.ts` 中的种子目录（含简介 `blurb`）。后续可替换为票务 API / 同步。
