# StageCue

演绎活动的**个性化推荐**与**开票 / 开演提醒**。

面向上海大歌剧院、上海大剧院等场馆的观演选场：按品类、城市、场馆、预算与关键词排序，并在本地设置提醒（浏览器通知 + 导出 ICS 日历）。

## 功能

- **口味画像**：歌剧 / 芭蕾 / 音乐剧 / 交响 / 话剧 / 戏曲 / 舞剧 / 室内乐；城市与场馆偏好；预算上限；关键词
- **只推未开票**：已开票场次默认不进推荐（秒空难追）；按口味 + 开票临近度排序
- **开票时间 + 双提醒**：每场展示开票时间；一点提醒同时写入「现在尽早」+「开票时刻」两条
- **提醒渠道**：① 浏览器 Notification（页开着时较稳）② 导出 `.ics` 进手机日历（推荐，含尽早+开票时刻闹钟）③ 暂无短信/微信/邮件
- **本地持久化**：`localStorage`（无需登录）
